# M1 页面与交互设计

日期：2026-11-02；先于前端实现保存。[布局草图](monitoring-m1-layout.svg)。

- 导航增加“告警中心”，沿用工作区侧栏、手机抽屉、主题与会话。
- 告警中心由“事件 / 规则 / 维护”三个页签组成。状态、节点、级别、时间筛选写入 URL；事件默认展示活跃项。桌面与手机均使用可阅读的事件卡片，避免依赖横向表格。详情显示触发、恢复、数据有效性、人工确认、有限期静默和投递记录；确认不改变指标状态。
- 规则在可滚动抽屉中纵向编辑。模板默认未启用，明确节点范围、匹配预览、指标、挂载点或带宽容量、阈值、持续时间、恢复阈值、重复间隔与渠道。维护时间使用带时区的 ISO 时间输入，内部 UTC。
- 系统设置保留账户密码与数据策略，新增通知渠道和投递记录。页面只读脱敏地址；编辑秘密时留空代表保留。密钥未配置时解释保存受限原因。测试通知和手动重试带加载状态。
- 节点详情保留原有页签，新增“流量套餐”和“事件”。套餐显示完整周期、独立计费流量、剩余额度、阈值、覆盖缺口及预测依据；编辑先预览再保存，变更不改原总流量或 Agent 网卡配置。
- 总览增加活跃告警与额度提醒入口，原有资源和节点状态继续展示。
- 表单由用户打开时初始化，自动刷新不覆盖未保存输入；按钮具有明确名称，抽屉关闭恢复焦点。宽度覆盖 1440 / 1024 / 768 / 390 / 320px，主题继承已有 tokens，减少动画偏好沿用现有规则。
