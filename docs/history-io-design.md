# 网卡流量与磁盘读写历史设计

## 页面与交互

沿用节点详情的深浅主题、卡片和移动端布局，保留资源监控、计费周期、系统信息及设置功能。

1. 共享时间范围：1 / 6 / 24 小时、7 / 30 天；聚合粒度可选自动、小时、天。自动在 24 小时以内使用分钟，长范围使用小时。
2. 网络卡片：全部历史监控网卡 / 单张网卡选择，速率 / 流量切换，下载和上传两条曲线，显示所选区间下载、上传、合计。
3. 磁盘卡片：全部整盘 / 单块磁盘选择，读取和写入两条速度曲线，显示所选区间累计读取、写入。无指标时提示等待采样或升级 Agent。
4. 筛选项放入 URL 查询参数，刷新和链接共享保留选择；后台实时刷新不重置筛选。移动端工具栏换行，图表保持完整宽度。
5. 缺失数据为空缺，零读写为零；加载、失败和旧 Agent 无数据分别展示。图表提供文字描述，选择器提供可访问名称。

布局草图见 [history-io-layout.svg](history-io-layout.svg)。

## 统计口径

- 网络直接使用按网卡保存的分钟字节增量，筛选后重新汇总；单网卡曲线不使用整机资源表中的合计速率。速率为字节增量除以桶的时间长度，当前未完成桶按已过时间计算。
- 磁盘采集 Linux 块设备计数器，复用现有 gopsutil。只选择没有下层 slave 的整盘设备，排除分区、loop、ram、光驱，避免 LVM/RAID 与底层设备重复累计；显示的是 VPS 可见块设备 I/O。
- 磁盘约每 5 秒采样，按真实间隔计算速度，跨分钟区间按重叠时长分摊字节；每个区间分摊字节总量保持精确。持久化设备、启动标识、原始计数器和采样时刻。
- 首次采样、系统重启、计数器下降、设备身份变化、不可读后恢复及大于 15 秒的采样间断只重建基线，曲线不制造尖峰。停止采集期间的磁盘读写不补记。
- 磁盘分钟记录保留 30 天，网络分钟历史维持长期保留。累计量使用整数字节和 JSON 十进制字符串，前端只在画图时转换为浮点数。

## 数据流与兼容

- Go Agent 新增磁盘采集与分钟存储模块，独立 `disk_baselines`、`disk_minutes`、同步游标；沿用单调 revision、分批发送及严格 ACK 校验。
- 上报协议 v1 增加可选 `disk_io` 分钟数组、快照磁盘速度数组和能力标识 `disk_io_supported`，ACK 增加可选 `disk_io`。中心接受旧 Agent 的原有上报。
- 中心库和 Agent 库均增量升级到 v2，仅新建磁盘表和索引，不改写原有网络、资源、凭据或配置记录。先升级中心，再升级 Agent。
- 历史 API 增加可选 `interface`、`device`、`granularity` 参数，返回可选设备、区间精确累计量及各时间桶的磁盘读写。原有 points / step / minutes 和资源指标保留。
- 小时/天速度按各磁盘实际观测时间加权，再合并设备；区间累计量仅汇总实际已采集字节。UI 明确速度为采样平均，磁盘历史只能从升级后开始。

## 验证

- Agent：首次/正常/空闲采样、跨分钟精确分摊、重启/归零/失联、整盘过滤、溢出回滚、分页补传、ACK 丢失和并发后续采样。
- 中心：v1 库迁移、旧上报兼容、重复与乱序幂等、事务回滚、大整数、网卡筛选、磁盘筛选、小时/天聚合、空缺、30 天保留。
- 页面：实际 API 与两个隔离的本机 Agent；网卡/磁盘切换、速率/流量、刷新保留筛选、失败及无数据；1440 / 768 / 390 / 320px、深浅主题、键盘交互和截图。

本设计只覆盖当前工作区实现与本地验证，不包含提交、部署或现有用户数据库迁移操作。
