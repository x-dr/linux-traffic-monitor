# M2-A 网络探测设计

日期：2026-11-02。实施范围为升级方案 M2-A，不包含 M2-B。新增能力默认关闭。

## 页面与交互

布局草图见 [SVG](monitoring-m2a-layout.svg)。沿用现有主题、卡片、抽屉及导航；增加 `/probes`，节点详情增加“网络质量”。

- 顶部显示任务数、当前失败及无有效观测数；URL 保存节点、任务和 1/6/24 小时、7 天窗口。
- 每个“执行节点 → 目标”单独显示最近结果、配置应用状态、观测可用率、覆盖率及有效/应执行分母。TCP/HTTP 使用失败率，ICMP 使用丢包率。
- 详情显示成功样本延迟、真实样本 P50/P95、证书到期时间及分页原始结果。缺口为空，不连接成健康曲线；旧版本历史明确标注版本。
- 创建/编辑使用纵向抽屉，支持节点多选、协议、IP 族、目标、周期、超时、渠道和启用开关。自动刷新不重置表单；Escape 关闭并恢复焦点。停用/归档保留历史。
- HTTP 仅 GET，不接收正文、鉴权头、URL 凭据、片段或查询参数。私网地址必须在 Agent 本地显式允许；敏感地址始终禁止。

## 传输与数据

中心 v3→v4；Agent v2→v3，迁移保留 source_id、凭据、所有原始表及游标。探测独立 revision/ACK，原上报仍是 v1。新 Agent 首次及断线重连使用基础字段协商 `probes:1`，独立原子持久化扩展配置。缺少探测 ACK 不推进探测流。请求上限 1.5 MiB，按流轮询删减最后一条记录，保留每流的最旧待传记录。

独立调度，最多 10 任务/节点、并发 2、默认 60 秒/3 秒、最短 15 秒。每个分配有稳定起点；重启只执行未来时刻，过去空缺由覆盖率体现；拥塞记录 skipped。目标超时不占用基础采集或上报 goroutine。断网保留已保存配置继续探测；中心明确撤回能力后暂停。

原始结果保留 7 天；Agent 清理未确认记录时持久记录丢弃数量与范围。中心以节点/source_id/sample_id 去重，旧版本和补传只入历史。新鲜有效执行连续 3 次失败触发、2 次成功恢复，跨缺口重新计数；证书 14/7/3 天按证书到期时刻和档位去重。复用现有事件、通知、维护与人工确认。

统计只使用保留的原始记录；可用率=成功/有效执行，覆盖率=有效执行/分配期间应执行次数。unsupported/blocked/skipped 无有效观测，不计目标故障。P50/P95 使用窗口内真实成功耗时。
