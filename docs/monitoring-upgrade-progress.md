## 发布前仍需验证

- 在实际部署数据库副本和目标环境验证升级/备份/回退；当前演练只使用隔离测试库。
- 配置并安全备份生产通知密钥，验证真实公网 HTTPS Webhook 接收；当前只做本地 HTTP 成功、重定向、超时和自签名 HTTPS 拒绝测试。
- 真实 VPS、systemd/OpenRC 常驻运行及 arm64 设备运行；本次两个真实 Agent 进程共用本机，arm64 只编译。
- 完整 Dockerfile 镜像重新构建与发布镜像验收；本次验证是缓存镜像运行时加当前只读编译产物。
- 同硬件、同数据集的升级前后 P95 对照与告警调度延迟观测；此次资源负载是代表性 5 分钟采样，不是 50 节点满量 30 天分钟记录。没有据此宣称上报增幅 ≤20% 或生产容量达标。
- 若需要恢复更旧的 **Agent** 数据库，先独立核实计数器基线、累计量和历史高水位；本工具不支持将旧 Agent 备份直接上线。
