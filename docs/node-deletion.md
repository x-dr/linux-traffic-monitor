# 删除节点

## 操作与界面

入口：VPS 管理 → 节点详情 → 节点设置 → 节点状态管理 → 删除节点。

```text
节点状态管理
停用、归档保留历史记录。
[停用节点] [归档节点]

永久删除会清除中心端节点及关联数据，无法恢复。
[删除节点]

┌ 永久删除节点？ ────────────────────┐
│ 节点名称                          │
│ 清除历史、告警、通知、资产和探测记录。│
│ 原 Agent 令牌失效；Agent 需自行停止。│
│                  [取消] [确认删除] │
└───────────────────────────────────┘
```

取消不发送请求。提交时显示加载状态并防止重复提交；失败留在确认框显示错误，可重试。成功返回节点列表，刷新列表、总览及关联查询缓存。手机与桌面复用同一个确认框，支持键盘操作和焦点返回。

## 删除范围

- `DELETE /api/v1/nodes/:id` 使用现有管理员会话、来源与 CSRF 校验，成功返回 `{ "ok": true }`；不存在返回 404，非法 ID 返回 400。
- 同一事务清除节点本体、流量/资源/磁盘/诊断/长期历史、同步状态、套餐、资产、告警事件与状态、探测分配/结果/状态、注册关联、通知及投递尝试，包括没有外键的关联表。任何一步失败全部回滚。无需升级数据库版本或 Agent。
- 共享探测任务仅移除该执行节点；已无执行节点的任务归档停用。告警规则和维护窗口移除该节点的显式范围；失去全部显式节点的规则停用，维护范围保持空集合。报表任务移除显式节点并递增版本；最后一个显式节点删除后停用任务，避免空范围被当作全部节点。共享通知渠道、注册令牌和已消耗注册次数保留。
- 历史报表仅移除被删节点行；包含该节点的报表通知及其投递尝试一并清除，保留其他节点的报表行。已发出的外部通知无法撤回；发送中的任务返回后不再写入已删除的投递记录。
- 中心不远程卸载或停止 Agent，也不删除 Agent 本地数据。旧节点令牌立即无法继续上报；重新接入须创建新节点，或使用仍有效且有剩余次数的注册令牌。

## 本地验证

覆盖管理员/CSRF/来源校验、完整关联清理与其他节点保留、事务失败回滚、旧令牌拒绝、共享配置范围、通知发送并发，以及桌面/手机确认、取消、错误重试和删除后导航。具体执行结果记录到升级进度文档。
